## 배경과 목표

구도윤은 앤드와이즈 재직 중 프론트엔드 개발자로 이직을 준비한다. 현재 doyoon.site는
구조(섹션·상세 페이지·다크모드·반응형)는 좋으나 shadcn/ui 기본 무채색 토큰을 그대로 써서
템플릿처럼 보이고, 히어로가 정체성을 전달하지 못한다.

목표: **CoKo의 게이미피케이션 감성을 사이트 아이덴티티로 끌어온 플레이풀 톤**으로 홈을
재구성한다. 단, 카피는 성과 중심을 유지해 "가벼운 지원자"로 보이지 않게 절제한다.

## 범위

**이번 단계 (디자인만):**

- 디자인 토큰 교체 — `src/styles/theme.css`
- 히어로 섹션 개편 — `src/features/hero/`
- 프로젝트 카드 위계 도입 — `src/features/project/`, 홈 그리드
- 경력 타임라인 스타일 갱신 + 앤드와이즈 자리 마련 — `src/features/experience/`
- Credentials 2단 카드 정리 — `src/features/credential/`
- 푸터 신설 — `src/components/layout/`

**다음 단계로 미룸 (콘텐츠):** 앤드와이즈·Hermes·cms-inspector 상세 문구/데이터 작성,
DevPortfolio 카드 잘못된 태그(NestJS·AWS) 데이터 수정, 블로그 카드 통일(썸네일 없는
카드·조회수 노출 정리).

## 핵심 결정

### 1. 컬러 토큰 (`src/styles/theme.css`)

| 역할 | 라이트 | 다크 |
|---|---|---|
| 배경 | `#fef6e4` 크림 | `#191632` 딥 네이비 |
| 잉크(글자·보더) | `#1f1a38` | `#f2effe` |
| 서브 텍스트 | `#57547a` | `#b8b4d9` |
| 카드 | `#fffdf8` | `#221e42` |
| 핑크(액션) | `#f582ae` / 소프트 `#fde3ef` | `#f582ae` / 소프트 `#3d2440` |
| 티얼(하이라이트) | `#8bd3dd` / 소프트 `#e0f4f7` | `#8bd3dd` / 소프트 `#1d3a44` |

- shadcn 토큰 매핑: `--background`·`--card`·`--foreground`·`--muted-foreground`를 위 값으로,
  `--primary`=핑크, `--accent`=티얼(+소프트 배경 토큰 신설). oklch로 변환해 기입.
- `--border`는 잉크가 아니라 **크림에 어울리는 소프트 헤어라인**(라이트 `#e9ddc4`,
  다크 `#2e2a52`)으로 교체 — 입력창·구분선 등 잔 요소가 과해지지 않게. 카드·버튼의 2px
  잉크 프레임은 전역 토큰이 아니라 해당 컴포넌트 클래스에서 명시적으로 적용한다.
- **역할 고정**: 핑크 = CTA·현재 타임라인 도트·대표작 그림자. 티얼 = 마커 하이라이트·실무
  태그·타임라인 라인·사진 프레임 그림자. 이 외 용도로 두 색을 쓰지 않는다.

### 2. 형태 언어

- 카드·버튼·칩·사진 프레임: 2px 잉크 보더 + 하드 섀도(카드 4px, 대표작 6px 핑크, 버튼 3px)
  + 라운드(카드 16px, 버튼·칩·태그 pill).
- 색이 아니라 형태가 플레이풀함을 담당한다. 본문 텍스트 영역에는 장식 없음.
- 기존 `--radius` 기반 radius 체계는 유지하되 카드류만 상향.

### 3. 히어로 (`src/features/hero/`)

- `_Profile` 제목 제거 → "👋 안녕하세요!" pill 배지 + 헤드라인:
  "재미있게 배우고, **단단하게 만드는** 프론트엔드 개발자 구도윤입니다."
  (강조부는 티얼 마커 하이라이트 — `linear-gradient(transparent 58%, teal 58%)`)
- 서브 한 줄(앤드와이즈 자동화 언급) + CTA 2개(이력서 보기, GitHub) + 스택 pill 칩.
- 기존 CapabilityCard 3장은 히어로에서 제거하고 서브 문장으로 압축.
- 사진: 증명사진 → 캐주얼 사진. 172×212 라운드 20px, 잉크 보더, 티얼 하드 섀도,
  `rotate(1.5deg)` 스티커 프레임. 에셋은 `public/`에서 기존 캐주얼 사진을 찾아 쓰고
  없으면 플레이스홀더 + 사용자에게 요청.

### 4. 프로젝트 위계 (홈 그리드)

- 1행: 대표작 CoKo(성과 불릿 2개+스크린샷 썸네일, 핑크 섀도) + cms-inspector(실무 태그).
- 2행: 미니 3 — Hermes(실무 태그), react-suspense-check, DoranDoran.
- `projectCardData.ts` 스키마에 `tier: 'featured' | 'sub' | 'mini'`, `badge?: 'work'` 추가.
- "실무" 태그는 티얼 소프트 배경 pill. 기존 `/card/[id]` 라우팅·오버레이는 그대로.
- Hermes·cms-inspector 카드의 상세 페이지 내용은 콘텐츠 단계에서 작성(이번엔 카드·스키마만).

### 5. 경력 타임라인 (`src/features/experience/`)

- 라인 = 티얼 3px, 도트 = 잉크 보더 원형(현재: 핑크 채움, 과거: 카드색 빈 도트).
- 최상단에 앤드와이즈 항목 추가 (2026.04 — 현재, 운영서비스팀 · CMS 운영). 상세 문구는
  콘텐츠 단계에서 확정하되 자리와 형식은 지금 잡는다.
- `Constant` 라벨 → `2024.06 — 현재` 날짜 형식으로 통일.

### 6. Credentials (`src/features/credential/`)

## 리스크

- 전역 토큰 교체라 블로그·상세·로그인 등 모든 페이지 배경이 크림으로 바뀜 → 전 페이지
  스모크 확인 필요. 콘텐츠 영역(markdown)은 카드 위에 얹어 가독성 보호.
- CapabilityCard 제거로 히어로 정보량 감소 → 내용은 서브 문장·상세로 흡수, 콘텐츠 단계에서 재확인.
- `projectCardData` 스키마 변경이 CardRenderer·상세에 파급 → 회귀 확인 필수.
- 캐주얼 사진 에셋 부재 시 히어로 미완성 → 플레이스홀더 + 사용자 제공 대기.
- 플레이풀 톤의 호불호 → 카피 절제 규칙(성과 중심 문어체)으로 완화, 사용자가 인지하고 선택함.
