       특히 네트워크가 느린 모바일 환경에서 사용자 이탈 우려가 컸습니다.

    <CaseStudy.Section title="구현 내용" dotColor="bg-blue-400">
      페이지별 진입 시점에 필요한 리소스만 로드하는 전략을 도입했습니다.

      1. `React.lazy`와 동적 `import()`를 사용하여 라우터 레벨에서 컴포넌트를 분리했습니다.
      2. `Suspense` 컴포넌트를 상위 트리에 배치하여, 청크(Chunk) 파일이 다운로드되는 동안 스켈레톤 UI를 노출해 UX 저하를 방지했습니다.

      <CaseStudy.Code>
      {`

const About = lazy(() => import('./pages/About'));
const Contact = lazy(() => import('./pages/Contact'));

return (

  <Suspense fallback={<PageSkeleton />}>
    <Routes>
      <Route path="/about" element={<About />} />
      <Route path="/contact" element={<Contact />} />
    </Routes>
  </Suspense>
);`}
      </CaseStudy.Code>
    </CaseStudy.Section>
