#  기술적 도전을 기록하는 개인 포트폴리오 웹사이트입니다.

## Key Features
* 수행한 프로젝트의 기술 스택, 기간, 핵심 성과 및 트러블슈팅 내역을 상세히 시각화하여 제공합니다.
* Supabase를 연동하여 개발 중 겪은 문제와 해결 과정을 기록하고 공유합니다.
* Interactive UI: Framer Motion을 활용한 부드러운 애니메이션과 Radix UI 기반의 접근성 높은 컴포넌트를 구성하였습니다.
* SEO & Performance: Next.js의 서버 사이드 렌더링(SSR)과 이미지 최적화를 통해 검색 엔진 최적화 및 빠른 로딩 속도를 구현했습니다.

## 🛠 Tech Stack
* Framework: Next.js 15 (App Router)
* Language: TypeScript
* Tailwind CSS, Framer Motion, Radix UI
* Supabase 
* Vercel
